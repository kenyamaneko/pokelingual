# 用語集

ドキュメント・コード・テスト名で使う、ドメインの概念を表す語。

| 用語 | コード | 説明 |
|---|---|---|
| 全国図鑑番号 | `pokedexNo` | 全国図鑑でポケモンに付けられた番号。このシステムでポケモンを識別する番号としても使う |
| 世代 | `generation` | ポケモンを全国図鑑番号の範囲で区切った分類 |
| クエスト | `quest` | ランダムに 1 匹のポケモンを選び、その図鑑の説明文を英語で表示して始まる、翻訳・名前当て・捕獲までの一連の流れ |
| 探索場所 | `location` | 出題するポケモンのタイプを決める場所 |
| 遭遇 | `encounter` | 出題されたポケモンへの挑戦が捕獲の結果まで終わったとき、図鑑に記録される回数 |
| 翻訳 | `translation` | 出題ポケモンの英語の図鑑説明文を、利用者が日本語に訳して入力する段階 |
| 採点 | `scoreTranslation` | AI が翻訳に点数を付けること |
| 素点 | `rawScore` | AI が付ける 0 から 100 の点数 |
| スコア | `score` | 素点を変換した 0 から 99 の点数。捕獲確率の計算に使う |
| 講評 | `review` | 博士が採点結果に添えるコメント |
| 採点結果 | `ScoreResponse` | スコアと講評をまとめて見せる画面 |
| 名前当て | `guessName` | 利用者が出題ポケモンの名前を答える段階 |
| 挑戦回数 | `attempts` | 名前当てで答えられる回数 |
| ヒント | `hint` | 挑戦回数を 1 回使って、出題ポケモンの情報を見ること |
| ボール種別 | `ballType` | 捕獲に使うボールの種類。モンスターボール、スーパーボール、ハイパーボール、マスターボールがある |
| 捕獲待機 | `CaptureStandby` | 利用者がボールを使う操作を待つ段階 |
| 捕獲 | `capture` | ボールを使ってポケモンを捕まえること |
| ユーザーごとの日次上限 | `perUserLimit` | 1 人が 1 日に AI 呼び出しできる回数の上限 |
| 全体の日次上限 | `globalLimit` | 全員の合計で 1 日に AI 呼び出しできる回数の上限 |
| ユーザーごとの AI 呼び出し回数 | `perUserCallCount` | 1 人が当日にすでに AI 呼び出しをした回数 |
| 全体の AI 呼び出し回数 | `globalCallCount` | 全員の合計で当日にすでに AI 呼び出しをした回数 |
| チュートリアルの完了状態 | `tutorialCompleted` | 利用者が初回チュートリアルを最後まで終えたかどうか |
