# 用語集

ドキュメント・コード・テスト名で使う、ドメインの概念を表す語。

| 用語 | コード | 説明 |
|---|---|---|
| 日次上限 | `dailyLimit` | 1 日に AI 呼び出しができる回数の上限。ユーザーごとの上限と全体の上限がある |
| AI 呼び出し回数 | `dailyUsage` | 当日にすでに AI 呼び出しをした回数。ユーザーごとと全体で数える |
| 世代 | `generation` | ポケモンを図鑑番号の範囲で区切った分類。出題の対象にする世代を利用者が選ぶ |
| 図鑑番号 | `pokemonID` | ポケモンを一意に識別する番号 |
| チュートリアルの完了状態 | `tutorialCompleted` | 利用者が初回チュートリアルを最後まで終えたかどうか |
